# GlamAvenue Website GA Badge Exports

This pack recreates the existing website GA monogram using the same source proportions as `Logo.tsx`.

- Website gold: `#C89B3C`
- Pure black background: `#000000`
- Circle: `cx=32`, `cy=32`, `r=29`, `stroke-width=1.5`
- GA: Playfair Display 600, size 30, centered at the website coordinates
- Star: exact website path and placement

## Masters

- Vector master: `svg/ga-badge-master.svg`
- Transparent vector master: `svg/ga-badge-master-transparent.svg`
- Black-background PNG master: `png/black-bg/ga-badge-2048.png`
- Transparent PNG master: `png/transparent/ga-badge-2048-transparent.png`

The smaller PNG files are high-quality downscaled exports of the 2048px masters.
